# "başlık" = include/modules/<başlık>.uxmh. Sayılar (işlev sayısı, DLL sembol denetimi, örnek durumu) üretici tarafından kaynaktan ve sonuç dosyalarından hesaplanır.
# "Dayandığı yazılım" yalnız DLL'in içeriğinden ya da sürüm dizgisinden doğrulananlar için yazılır; doğrulanmayan "—" olur.
# Kategori sırası = kılavuzdaki tablo sırası.

# ---------- Veri biçimleri ve metin ----------
uxjson :: Veri biçimleri ve metin :: yyjson :: JSON metnini ayrıştırır (Parse), nesne/dizi/değer arasında gezinir (Root, ObjectGet, ArrayGet, PointerGet), değeri tipine göre okur (GetString, GetI64, GetF64, GetBoolean) ve yeniden metne yazar (Write). Nesne üretici yoktur: gönderilecek JSON'u metin birleştirerek kurarsınız.
uxregex :: Veri biçimleri ve metin :: PCRE2 :: Düzenli ifade derler (Compile) ve metinde eşleştirir (Match, IsMatch); eşleşen grupların sayısını, başlangıç/bitiş konumunu ve metnini verir. Desen derlenemezse neden okunamaz (G-KUT-22).
uxconfig :: Veri biçimleri ve metin :: — :: INI biçimli ayar dosyası: bölüm ve anahtar okuma/yazma (GetString, GetI64, GetF64, GetBoolean ve Set karşılıkları), anahtar ve bölüm silme, anahtar sorgulama.
uxlog :: Veri biçimleri ve metin :: — :: Düzeyli günlük dosyası (Trace, Debug, Info, Warning, Error, Fatal); en düşük düzey ayarlanınca altındaki satırlar elenir; her satıra zaman damgası yazılır.
uxuuid :: Veri biçimleri ve metin :: — :: Rastgele UUID üretir (NewUuid), geçerliliğini ve eşitliğini denetler, biçimini düzenler (Normalize, WithoutBraces).
uxpath :: Veri biçimleri ve metin :: — :: Dosya yolu metinleriyle çalışır: birleştirme, normalleştirme, dosya adı/klasör/uzantı ayırma, uzantı değiştirme, bir yolun başka bir yolun içinde olup olmadığını sınama. Kısmen sorunludur (G-KUT-1).

# ---------- Dosya, sistem ve süreç ----------
uxfs :: Dosya, sistem ve süreç :: — :: Dosya ve klasör işlemleri: var mı, oluştur, sil, kopyala, taşı, boyut, öznitelik, metin dosyasını tamamen oku/yaz/ekle ve klasör içeriğini sıralı gez (EnumOpen/EnumNext).
uxsystem :: Dosya, sistem ve süreç :: Windows API :: Bilgisayar ve kullanıcı adı, özel klasörler (geçici, Windows, çalışma), ortam değişkenleri, işlemci sayısı, bellek durumu, mimari, yönetici hakkı, ekran boyutu ve zaman sayacı gibi sistem bilgileri.
uxprocess :: Dosya, sistem ve süreç :: Windows API :: Dış program başlatır (Start), bitmesini bekler (Wait), çıkış kodunu okur (ExitCode), sonlandırır (Kill); tek çağrılık RunWait ve ShellOpen kısayolları vardır.
uxarchive :: Dosya, sistem ve süreç :: libarchive :: ZIP, TAR ve benzeri arşivlerin giriş sayısını okur (EntryCount) ve hepsini açar (ExtractAll). Zip-slip girişlerini (`../x`, `/x`) reddeder; Latin-1 dışı harfli (ğ, ı, ş …) dosya adlarını açamaz (G-KUT-18).
uxcompress :: Dosya, sistem ve süreç :: zstd :: Bellekteki veriyi ve dosyaları sıkıştırır/açar (Compress, Decompress, CompressFile, DecompressFile); sonuç "blob" tutamacıdır, BlobData/BlobSize ile okunur, BlobFree ile bırakılır.
uxcrypto :: Dosya, sistem ve süreç :: libsodium :: SHA-256 özeti (Sha256Text, Sha256Hex), kriptografik rastgele bayt (RandomBlob), parola özeti ve doğrulama (PasswordHash, PasswordVerify) ve gizli anahtarlı şifreleme (SecretboxEncrypt/Decrypt).
uxdatetime :: Dosya, sistem ve süreç :: — :: Unix milisaniyesi cinsinden an: şimdiki zaman, ISO 8601 ayrıştırma ve biçimleme (ParseUtc, FormatUtc), toplama ve fark, uyku, yüksek çözünürlüklü sayaç. Yalnız `YYYY-AA-GGTSS:DD:SSZ` biçimine güvenin (G-KUT-7, G-KUT-8).

# ---------- Ağ ----------
uxhttp :: Ağ :: libcurl :: HTTP/HTTPS istemcisi: adres, yöntem, başlık, gövde, zaman aşımı ve yönlendirme ayarlanır; Perform isteği yapar; Status, ResponseText ve SaveResponse yanıtı verir. Dönüş değerleri tek tip değildir (G-KUT-11).

# ---------- Veri tabanı ve çözümleme ----------
uxsqlite :: Veri tabanı ve çözümleme :: SQLite :: Gömülü SQL veri tabanı: dosya ya da bellek veri tabanı açar, SQL çalıştırır (Exec), hazırlanmış sorguya değer bağlar (BindI64/F64/Text), satır satır okur (Step, ColumnX). `Exec` ve `Step` SQLite'ın ham sonuç kodunu döndürür (0 tamam, 100 satır var, 101 bitti); `Open` başarısızsa neden okunamaz (G-KUT-22).
uxdataframe :: Veri tabanı ve çözümleme :: DuckDB :: Sütunlu veri çerçevesi: CSV ve Parquet yükler, SQL sorgusu çalıştırır (Exec, Query), süzer (Filter), sıralar (OrderBy), gruplar (GroupMean), birleştirir (JoinInner) ve CSV'ye yazar (ToCSV). DuckDB DLL'i bulunabilmelidir (G-KUT-4).
uxdataset :: Veri tabanı ve çözümleme :: — :: Makine öğrenmesi için veri kümesi: CSV yükleme, karıştırma, eğitim/sınama bölme, ölçekleyici (standart, min-maks), eksik değeri ortalamayla doldurma, küçük parti (batch) yükleyici.
uxcollections :: Veri tabanı ve çözümleme :: GLib :: Liste (54 işlev), sözlük (37), çift uçlu kuyruk (33), yığın (21), kuyruk (21), küme (21) ve ağaç (13) koleksiyonları; sayı ve metin tutar, sıralar, toplam/ortalama gibi özetler verir.
uxcollections_aliases :: Veri tabanı ve çözümleme :: — :: `uxcollections` için kısa "LISTADD" tarzı adlar (dil düzeyindeki ALIAS ile). ALIAS bir INCLUDE sınırını aşmaz: yalnız aynı dosyada yazılırsa işe yarar (Bölüm 16).
uxgraph :: Veri tabanı ve çözümleme :: — :: Çizge (graf) çözümlemesi: köşe ve kenar ekleme, derece, yoğunluk, bileşenler, en kısa uzaklık, yol var mı, üçgen sayısı, BFS uzaklıkları.

# ---------- Sayısal hesap ----------
uxmath :: Sayısal hesap :: — :: Polinom (değer, türev, integral, kök bulma: ikiye bölme ve Newton, Simpson integrali), lojistik denklem için Euler ve RK4 çözücüleri, etkinleştirme işlevleri, vektör ve matris işlemleri. Önek: UXMATH_.
uxmathcore :: Sayısal hesap :: — :: Tipli sayısal tamponlar (I8, U8 … F64): oluştur, dilimle, kopyala, tip değiştir (Cast), F64 vektör aritmetiği (toplama, ölçekleme, iç çarpım, norm). Önek: UXMC_.
uxmatrix :: Sayısal hesap :: OpenBLAS :: Matris cebiri: çarpım, devrik, determinant, ters, iz, normlar, doğrusal denklem çözme (Solve).
uxtensor :: Sayısal hesap :: OpenBLAS :: 1–4 boyutlu F64 tensörler: eleman erişimi, dilim (kopya), eleman eleman işlemler, toplam/ortalama/iç çarpım/norm, matris çarpımı (MatMul, MatVec) ve devrik.
uxstats :: Sayısal hesap :: — :: Betimsel istatistik: ortalama, ortanca, varyans, standart sapma, yüzdelik, korelasyon, doğrusal regresyon. Önek: UXSTATS_.
uxstats2 :: Sayısal hesap :: — :: Çıkarımsal istatistik: t testleri (tek, Welch, havuzlu, eşli), z testleri, oran testleri, F testi, ki-kare, tek yönlü ANOVA ve post hoc (Bonferroni, Tukey, Scheffé), regresyon F, Durbin-Watson, ADF. Önek: UXSTATS2_.
uxgsl :: Sayısal hesap :: GNU Scientific Library 2.8 :: Özel fonksiyonlar (Gama, Erf, Bessel), rastgele sayı üreteci, vektör/matris, karmaşık sayı, sayısal integral (QAG) ve ikiye bölme ile kök bulma; integral ve kök için `CODEPTR` geri çağrısı gerekir (yalnız x64).

# ---------- Yapay zekâ ----------
uxaimath :: Yapay zekâ :: — :: Sinir ağı çekirdeği: etkinleştirme işlevleri (sigmoid, ReLU, GELU, Swish …), softmax, kayıp işlevleri (MSE, MAE, Huber, çapraz entropi), SGD ve momentum güncellemesi, eğim kırpma, ağırlık başlatma, yoğun katman ileri hesabı. `uxtensor` önce eklenmelidir (G-KUT-14).
uxnn :: Yapay zekâ :: — :: Tek nöron, yoğun katman ve ağ nesneleri; ağ eğitimi (NetworkTrainMSESGDPtr), tahmin (ileri hesap, en büyük çıktı sınıfı). Ağa eklenen katmanın sahibi ağdır (G-KUT-9).
uxnn2 :: Yapay zekâ :: — :: Katman ekleyerek (AddDense) kurulan ağ; seçilebilir en iyileyici (SGD, momentum, Adam), tek örnek ve dizi eğitimi, ağırlık okuma/yazma, ağı dosyaya kaydetme ve yükleme. Dikkat: `OPT_SGD` ve `OPT_MOMENTUM` sabitleri uxnn2'de 0 ve 1, uxnn3'te 1 ve 2'dir; sabiti her zaman ad alanıyla yazın (`uxnn2.OPT_ADAM`).
uxnn3 :: Yapay zekâ :: — :: Veri kümesi ve model bir arada: CSV yükle, ölçekle, eğitim/sınama böl, model kur, eğit (TrainDataset), MSE ve ikili doğruluğu ölç, modeli kaydet/yükle. Eğitim sonuçları aynı işlemde tekrarlanamaz (G-KUT-17).
uxonnx :: Yapay zekâ :: ONNX Runtime :: ONNX model dosyasını yükler (SessionCreate), giriş/çıkış bilgisini verir, tensör oluşturup modeli çalıştırır (Run1). .onnx dosyası gerekir; bu depoda model olmadığı için sınanmadı.
uxonnx2 :: Yapay zekâ :: ONNX Runtime :: `uxonnx`'in genişletilmiş sürümü: sağlayıcı seçimi, giriş/çıkış tipi ve boyut sorguları. .onnx dosyası gerekir; sınanmadı.
uxllama :: Yapay zekâ :: llama (dış komut satırı programı) :: Yerel dil modelini llama komut satırı programı üzerinden çağırır: model yolu, iş parçacığı, bağlam, sıcaklık, Top-P/Top-K, tohum ayarlanır; Prompt metin ve PromptFile dosya gönderir. Dış program ve model dosyası gerekir; sınanmadı.
uxllamax :: Yapay zekâ :: llama (dış komut satırı programı) :: `uxllama`'nın aynı DLL'i kullanan sürümlü genişletmesi (Version işlevi ekli). Sınanmadı.

# ---------- Mantık ve betik köprüleri ----------
uxlogic :: Mantık ve betik köprüleri :: Lua 5.4 :: Lua betiği çalıştırma (LuaDoString, LuaDoFile, değişken okuma/yazma), Prolog sorgusu ve bulanık mantık işlevleri (Triangle, Trapezoid, FuzzyAnd/Or/Not, Weighted). DLL'de bir sembol eksiktir; x64'te bu yüzden program başlamaz (G-KUT-2).
uxpython :: Mantık ve betik köprüleri :: Python (makinede kurulu) :: Gömülü Python oturumu: modül içe aktarma, işlev çağırma (bağımsız değişkenler JSON metniyle), sonucu tamsayı/ondalık/metin/JSON olarak alma. Kendi Python'unu getirmez, makinedekini yükler (G-KUT-13).
uxjsruntime :: Mantık ve betik köprüleri :: QuickJS :: JavaScript çalıştırır: çalışma zamanı ve bağlam oluşturur, bellek/yığın/süre sınırı koyar, betik ya da dosya değerlendirir, JavaScript işlevini JSON bağımsız değişkenlerle çağırıp sonucu JSON olarak alır. Sonuç için JsBootstrapUxb şarttır (G-KUT-12).
uxwasmrt :: Mantık ve betik köprüleri :: wasmtime :: WebAssembly modülü yükler ve çekirdek i32 işlevlerini çağırır (WasmCallI32_0 … 4). İçe aktarması olan modülü reddeder; uXBasic'in kendi WASM çıktısı bu yüzden yüklenmez (G-WASM-10).

# ---------- Nesne altyapısı ve yardımcılar ----------
uxclazz :: Nesne altyapısı ve yardımcılar :: — :: Derleyicinin ürettiği sınıf kodunun kullandığı küçük yardımcılar: karma (hash) birleştirme, metin karması, JSON kaçışlama. Doğrudan kullanılmak için yazılmamıştır.
uxclz :: Nesne altyapısı ve yardımcılar :: — :: uXBasic `CLASS` sisteminin yerine geçmeyen, bağımsız ikinci bir nesne kayıt defteri (C++): tür, arayüz ve yöntem kaydı, nesne sarmalama ve başvuru sayımı, tür sorgulama.
uxclz_object :: Nesne altyapısı ve yardımcılar :: — :: `uxclz` tutamaçlarını sarmalayan `UxClzObject` sınıfı (Attach, IsValid, Retain, QueryInterface, Close); yıkıcısı sahip olduğu tutamacı bırakır. Ayrı işlev değil, bir sınıf sunar.
uxscalar_module :: Nesne altyapısı ve yardımcılar :: — :: Üç işlevli en küçük örnek kütüphane (uxscalar_init, uxscalar_add, uxscalar_shutdown); kendi kütüphanenizi yazarken şablon olarak bakılır.
uxcapi :: Nesne altyapısı ve yardımcılar :: — :: Genel C çağrı arayüzü: tür/yapı/birlik tanımlama ve dinamik çağrı kurma (108 işlev). DLL bu makinede yüklenemiyor (G-KUT-3).

# ---------- Grafik, oyun ve konsol ----------
uxsdl3 :: Grafik, oyun ve konsol :: SDL3 :: Pencere, çizim, olay, ses ve girdi (334 işlev, 387 sabit). Başlık çok büyüktür ve yüklemesi uzun sürer (G-HIZ-3). Ayrıntılı rehber docs klasöründedir.
uxraylib :: Grafik, oyun ve konsol :: raylib + raygui :: Pencere, 2B çizim, doku, yazı tipi, ses, arayüz bileşenleri ve çarpışma işlevleri (175 işlev).
uxraylib_3d :: Grafik, oyun ve konsol :: raylib :: `uxraylib` ve matematik başlığının üstüne işlemci tarafı 3B işlevlerini (kamera: CameraCreate, CameraUpdatePro, CameraMatrix; küre ve kutu çarpışmaları) ekleyen başlık (350 işlev; aynı ad alanı, aynı DLL).
uxraylib_math :: Grafik, oyun ve konsol :: raylib :: `uxraylib`'in üstüne vektör ve matris matematiğini (Clamp, Lerp, MatrixMultiply, MatrixRotate, MatrixPerspective, MatrixInvert …) ekleyen başlık (330 işlev; aynı ad alanı, aynı DLL).
uxterminal :: Grafik, oyun ve konsol :: — :: ANSI renkli konsol çizimi: metin, hücre, çizgi, kutu, sprite, tuş okuma, pencere boyutu ve dikdörtgen çarpışması. Etkileşimli konsol gerekir; sınanmadı.
