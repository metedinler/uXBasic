=== uXBasic CLI Compiler Infrastructure ===
Kullanım: uxb <verb> [kaynak.uxb] [seçenekler...]
          uxb @komutlar.uxcli (Toplu komut dosyası calistirir.)
          <komutlar>.uxcli (Toplu komut dosyasıdir)
================================================================================
uXBasiC komut satırı yalnız çalıştırmak için değildir; öğrenmek için de kullanılır.
Bir genç programcı seçeneklerle kendi yazdığı programın iç organlarını görebilir.
Bu, derleyici yazmayı öğrenmenin kısa yoludur.
================================================================================

VERBLER (Aşama Seçiciler):
  lex   : Lexer / token üretimi            | par   : Sadece syntax kontrol
  ast   : AST üretimi & contract check     | sem   : Semantic analiz & type binding
  hir   : HIR üretimi                      | mir   : MIR üretimi ve doğrulama
  int   : AST interpreter ile çalıştırma   | x64   : x64 NASM üretimi + build
  jsw   : JavaScript / Web backend         | wat   : WAT üretimi
  bld   : Tam x64 build pipeline           | run   : Programı çalıştır (interpreter)
  chk   : Toplu doğrulama (validate-all)   | fmt   : Format kontrolü
  map   : Source map üretimi               | doc   : Dokümantasyon üretimi
  rel   : Release gate kontrolü            | hlp   : Detaylı yardım
  ver   : Versiyon bilgisi

GENEL VE KONTROL SEÇENEKLERİ (Tetikleyiciler ve Bayraklar):
  --format-check          : Biçimlendirme kontrolünü aktif eder.
  --help                  : Genel yardım menüsünü gösterir.
  --version               : Derleyici sürüm bilgisini basar.
  --target <hedef>        : Hedef platform seçer (x64, js, wat, wasm, browser).
  --stop-after <aşama>    : Belirtilen derleme aşamasında durur.
  --diag-format           : Tanı/Hata mesajlarının çıktı formatını ayarlar.
  --strict                : Katı mod kurallarını devreye alır.
  --time-passes           : Derleyici aşamalarının çalışma sürelerini raporlar.
  --parse-only            : Sadece parser katmanını çalıştırır.
  --semantic              : Semantik analizi zorunlu kılar.
  --mir-verify            : MIR katmanı doğrulamayı tetikler.
  --execmem               : Kod üretimi için dinamik bellek yürütmesini açar.
  --interpreter-backend   : Yorumlayıcı motorunun arkasındaki katmanı seçer.
  --max-steps <N>         : Yalnız yorumlayıcılar: en çok N adım (0 = sınırsız, varsayılan).
  --task-workers <N>      : Native SPAWN işçi sayısı (1..1024, varsayılan: CPU sayısı).
  --validate-all          : Tüm doğrulama adımlarını çalıştırır.
  --validate-all-fail-fast: İlk hatada doğrulamayı keser.
  --source-map            : Kaynak haritası (source-map) üretimini tetikler.
  --doc                   : Otomatik dökümantasyon motorunu çalıştırır.
  --release-gate          : Canlıya alım (production) kapısı kontrollerini yürütür.
  --extract-src           : Gömülü kaynak kodları ayrıştırır.
  --console-mode          : Konsol çıktı modunu yapılandırır.
  --interop               : Harici dil bağlama (interoperability) modunu açar.
  --codegen / --x64gen    : Native kod üreticilerini tetikler.
  --debug / --ayikla      : Derleyici içi hata ayıklama (debug) çıktısını açar.
  --quiet / --sessiz      : Log çıktılarını kapatır, sadece hataları basar.
  --trace / --hook-trace  : Derleyici adımlarını ve hook'ları izler.
  --extfp-strict          : Genişletilmiş sabit nokta (ExtFP) katı modunu açar.
  --enable-extfp-runtime  : ExtFP çalışma zamanı desteğini aktif eder.
  --adim25-27-close-gate  : Adım 25-27 arası optimizasyon kapısını kapatır.
  --adim25-26-27-close-gate: Adım 25-27 tam optimizasyon kapısını kapatır.

HEDEF EMIT TETİKLEYİCİLERİ (Tek Başına Yazılır):
  --emit-js               : JavaScript kod üretimi modunu açar.
  --emit-wat              : WebAssembly Text (WAT) üretim modunu açar.
  --emit-wasm             : WebAssembly ikili (WASM) üretim modunu açar.
  --emit-browser          : Tarayıcı uyumlu HTML/JS üretim modunu açar.
  --emit-nasm             : x64 NASM Assembly üretimini tetikler.
  --emit-x64-nasm         : x64 NASM Assembly üretim modunu açar.
  --build-x64             : Üretilen x64 kodunu doğrudan EXE'ye derler.
  --wat2wasm[=<yol>]      : WAT -> WASM dönüştürücüsünü varsayılan veya verilen yoldan çalıştırır.

ÇIKTI DOSYA HEDEFLERİ (Arkasına Mutlaka Dosya/Klasör Yolu İster!):
  --js-out <dosya.js>     : Üretilen JavaScript kodunun yazılacağı dosya.
  --wat-out <dosya.wat>   : Üretilen WebAssembly Text kodunun yazılacağı dosya.
  --wasm-out <dosya.wasm> : Üretilen binary WASM kodunun yazılacağı dosya.
  --html-out <dosya.html> : Üretilen tarayıcı arayüzünün yazılacağı dosya.
  --emit-x64-nasm-out <f> : NASM assembly çıktısının kaydedileceği dosya.
  --x64gen-out <klasör>   : Üretilen yerel x64 binary dosyalarının klasörü.
  --build-x64-out <exe>   : Derlenecek nihai Windows EXE dosyasının adı/yolu.
  --out-root <klasör>     : Tüm çıktıların yazılacağı kök dizin (Örn: build/).
  --artifact-root <klas>  : Ara derleme dosyalarının (artifact) kök dizini.
  --extfp-runtime-dir <d> : ExtFP runtime kütüphanelerinin aranacağı dizin.

İÇ ORGAN ANALİZİ VE JSON/CSV ÇIKTILARI (Dosya Yolu İster):
  --json-out <dosya>      : Genel derleme raporunu JSON formatında yazar.
  --error-limit <sayı>    : Maksimum hata limiti ve hata raporlama dosyası.
  --token-json-out <f>    : Standart token akışını JSON olarak kaydeder.
  --tokens-json-out <f>   : Gelişmiş lexer token listesini JSON olarak kaydeder.
  --parser-json-out <f>   : Parser (Sözdizimi) ağaç analiz raporunu yazar.
  --ast-json-out <dosya>  : Soyut Sözdizimi Ağacını (AST) JSON olarak dışa aktarır.
  --ir-json-out <dosya>   : Ara Seviye Temsili (IR) verilerini yazar.
  --hir-json-out <dosya>  : High-Level IR (HIR) analiz çıktısını yazar.
  --mir-json-out <dosya>  : Medium-Level IR (MIR) temel analiz çıktısını yazar.
  --mir-full-json-out <f> : Tüm MIR kontrol akış grafiğini (CFG) JSON yazar.
  --semantic-json-out <f> : Semantik analiz ve tip bağlama raporunu yazar.
  --backend-report-json-out : Arka yüz (backend) kod üretim matris raporunu yazar.
  --source-map-json-out <f> : Kaynak kod-hedef kod eşleşme haritasını JSON yazar.
  --doc-json-out <dosya>  : Üretilen API ve dil dökümantasyonunu JSON yazar.
  --release-json-out <f>  : Release kapısı test sonuç raporunu JSON yazar.
  --run-report-json-out <f>: Interpreter çalıştırma metriklerini raporlar.
  --log-out / --debug-log-out <f> : Derleyici iç loglarını dosyaya kaydeder.
  --stdout-out / --stderr-out <f> : Standart çıktıları dosyaya yönlendirir.

GELİŞMİŞ KATMAN VE MATRİS RAPORLARI (Anlamları ve Kullanımları):
  --lexer-diagnostics-json-out <f>   : Lexer aşaması detaylı hata/uyarı tanı raporu.
  --parser-diagnostics-json-out <f>  : Parser aşaması sözdizimi hata ve tanı raporu.
  --semantic-diagnostics-json-out <f>: Semantik (anlam) analizi ve tip tanılama logu.
  --mir-opt-report-json-out <f>      : MIR optimizasyon adımları ve yapılan dönüşümler.
  --symbol-table-json-out <f>        : Değişken, fonksiyon ve kapsam (scope) sembol tablosu.
  --type-table-json-out <f>          : Derleyicinin dahili tip matrisi ve kullanıcı tipleri.
  --layout-report-json-out <f>       : Bellek yerleşimi, struct boyutları ve padding raporu.
  --hir-inventory-json-out <f>       : High-Level IR nesnelerinin ve düğümlerinin dökümü.
  --inventory-json-out <f>           : Genel derleyici kaynak ve bileşen envanteri.
  --pipeline-json-out <f>            : Derleyici aşamalarının yürütme sırası ve durumları.
  --mir-pipeline-json-out <f>        : MIR optimizasyon ve lowering boru hattı akışı.
  --mir-opcodes-json-out <f>         : Üretilen MIR opkodlarının (buyruklarının) tam listesi.
  --mir-surface-json-out <f>         : MIR kontrol akış grafiğinin yüzeysel şeması.
  --mir-module-json-out <f>          : Modül düzeyindeki MIR yapısı ve global tanımlar.
  --mir-verify-json-out <f>          : MIR doğrulama (verification) test sonuç raporu.
  --artifact-report-json-out <f>     : Derleme sonucu oluşan tüm ara dosyaların (artifact) listesi.
  --ast-contract-json-out <f>        : AST sözleşme (contract) tanımlarının ham JSON dökümü.
  --ast-contract-report-json-out <f> : AST katmanı sözleşme ihlalleri ve uyumluluk raporu.
  --ast-contract-matrix-out <f>      : Hangi AST düğümünün hangi sözleşmeye bağlı olduğu matrisi.
  --session-live-json-out <f>        : Canlı derleme oturumu çalışma zamanı metrikleri.
  --layer-timing-json-out <f>        : Derleyici katmanlarının (lex, par, ast) mikrosaniye süreleri.
  --trace-json <f>                   : Derleyicinin tüm adımlarının adım adım izleme (tracing) verisi.
  --runtime-trace-json-out <f>       : uXBasic kodunun çalışma zamanı izleme/profil logları.
  --x64-codegen-policy-json-out <f>  : x64 kod üretimi sırasında uygulanan register/ABI politikaları.
  --extfp-policy-json-out <f>        : Genişletilmiş Sabit Nokta (ExtFP) hassasiyet politikaları.
  --program-output-json-out <f>      : Hedef programın ürettiği konsol çıktılarının JSON özeti.
  --program-output-out <f>           : Hedef programın ham standart çıktı (stdout) yönlendirmesi.
  --final-screen-json-out <f>        : Program sonlandığında oluşan bellek/ekran durum dökümü.
  --ast-contract-check               : AST katmanı sözleşme denetimlerini zorunlu tetikler.
  --debug-token-dump                 : Lexer'ın ürettiği tüm tokenleri anlık ekrana basar.
  --dump-ast                         : AST yapısını terminale insan okuyabilir formatta basar.
  --dump-mir                         : MIR yapısını ve kontrol akış grafiklerini terminale basar.
  --run-id <kimlik>                   : Çalışma oturumuna özel ID atar.

ÖRNEK KULLANIMLAR (Derleyiciyi Öğrenmek İçin):
  uxb ast main.bas --dump-ast --ast-json-out build/ast.json
  uxb sem main.bas --symbol-table-json-out build/symbols.json --type-table-json-out build/types.json
  uxb mir main.bas --dump-mir --mir-opcodes-json-out build/opcodes.json --mir-opt-report-json-out build/opt.json

AYRI İŞLEV KULLANIM ÖRNEKLERİ (Doğru ve Yanlış Kombinasyonlar):
  DOĞRU (Adım adım ve parametreli):
    uxb jsw main.uxb --emit-js --js-out build/app.js
    uxb x64 main.uxb --emit-x64-nasm --emit-x64-nasm-out build/out.asm
    uxb bld main.uxb --build-x64 --build-x64-out bin/oyun.exe
    uxb ast main.uxb --ast-json-out build/ast_yapisi.json
