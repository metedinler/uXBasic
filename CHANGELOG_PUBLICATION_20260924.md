# Public publication record - 2026-09-24

This file records the first Git-tracked publication boundary. Each group is
kept in a separate commit so the reason for the change is visible in Git
history.

1. Legal and publication policy: licenses, design-rights notice, third-party
   notice, README, and ignore rules. Purpose: define permitted use and prevent
   private/oversized material from entering the public source tree.
2. Compiler and runtime source: source, headers, manifests, library source,
   examples, and selected tests. Purpose: publish reproducible implementation
   material without generated binaries and historical staging output.
3. User manuals: the three root `.docx` manuals and their corresponding public
   Markdown manuals. Purpose: provide user documentation while excluding
   private design decision records.
4. Distribution manifest and release bundle: selected current Windows x64
   executable/DLL set, checksums, and component notice. Purpose: provide a
   reproducible release asset without committing the large `dist` tree.
