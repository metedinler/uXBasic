# uXBasic 0.1.0-preview.20260924

This is a source and documentation publication of the uXBasic compiler project.

## Included

- Compiler, frontend, runtime, native integration, library, and manifest source.
- Selected compatibility and language tests that are suitable for public review.
- User manuals and technical guides, including DOCX manuals.
- A Windows x64 distribution archive containing the current command-line tools,
  runtime DLLs, licenses, notices, and manuals.

## Deliberately excluded

- Private design and coordination records.
- Internal AI coordination notebooks and work logs.
- Retired, temporary, duplicate, and generated test trees.
- Large development `dist` documents and unrelated archives.

The excluded material remains local to the development workspace and is not part
of the public source publication.
