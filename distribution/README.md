# uXBasic Windows x64 preview distribution

The binary bundle for this publication is the GitHub Release asset
`uxbasic-windows-x64-20260924.zip`. It is intentionally kept out of the Git
source tree because it contains compiled executables and third-party DLLs.

The bundle contains the current `uxb.exe`, the matching runtime/providers,
the experimental `uxb_claude1_s030.exe` build clearly marked as experimental,
the three user manuals, license notices, and `release_manifest.json` with a
SHA-256 entry for every included file.

This is a preview distribution. The experimental TASK build is not presented
as a completed asynchronous runtime. Check the manifest and third-party
notices before redistribution.
