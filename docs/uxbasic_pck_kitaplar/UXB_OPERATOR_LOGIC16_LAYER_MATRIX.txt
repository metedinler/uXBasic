# Operatör katman matrisi

| Katman | Dosya/alan | Sorun | Yapılacak işlem |
|---|---|---|---|
| Lexer keyword | `src/parser/lexer/lexer_keyword_table.fbs` | TRUE/FALSE ve Logic16 yok | Keyword listesine TRUE/FALSE/NAND/NOR/XNOR/IMP/CIMP/NIMP/NCIMP/IDA/IDB/NOTA/NOTB/ZERO/ONE/NXOR/EQV/EQA/IFF ekle |
| Lexer op reader | `src/parser/lexer/lexer_readers.fbs` | `==`, `**=` yok | ReadOperatorOrPunct içine `**=`, `==` ekle |
| Parser op contract | `src/parser/parser/parser_adim08_operator_contract.fbs` | `\` yazımı ve öncelikler tutarsız | Tek kaynak öncelik tablosu ile değiştir |
| Parser expr primary | `src/parser/parser/parser_expr.fbs` | TRUE/FALSE IDENT/KEYWORD_REF olabilir | TRUE/FALSE -> BOOLEAN node yap |
| Parser relation | `parser_expr.fbs` | `=` relation değil | `=` ve `==` relation olarak parse edilecek |
| Parser assignment | `parser_expr.fbs` | `=` expression assignment | `=` expression assignment listesinden çıkarılacak; statement registry atamayı yakalayacak |
| Parser logic16 | `parser_expr.fbs` | türev mantık yok | ParseLogicAnd/ParseLogicXor/ParseLogicOr seviyelerine ekle |
| AST | `ast*.fbs` | generic node var, op sözleşmesi eksik | BINARY/UNARY/TERNARY çocuk modeli kesinleştir; exporter op alanını yazsın |
| Semantic | `semantic_pass_tail.fbs` | yeni op tipleri yok | Logic16 sonucu BOOLEAN, POW numeric olarak işaretlenecek |
| MIR model | `semantic/mir_model.fbs` | POW/Logic16 const eksik | MIR_OP_POW ve Logic16 constları eklenecek |
| MIR map | `semantic/mir.fbs` | map eksik/çakışmalı | `**->POW`, `^->XOR`, Logic16 -> opcode |
| MIR lowering | `semantic/mir_lower_expr.fbs` | TRUE/FALSE ve logic16 eksik | literal/lowering eklenecek |
| MIR evaluator | `semantic/mir_evaluator*.fbs` | Logic16 yok, POW eksik olabilir | truth table uygulanacak |
| AST interpreter | `interpreter/ast/ast_interp_expr.fbs` | Logic16 yok; unary/ternary çocuk karışık | Binary truth table + unary/ternary kanonik okuma |
| MIR interpreter | `interpreter/mir/mir_interp_arith.fbs` | Logic16 yok | MIR op çalıştırma ekle |
| JS codegen | `codegen/js/js_expr_emit.fbs` | Logic16 yok | JS şablonları ekle |
| WASM codegen | `codegen/wasm/wasm_instr_emit.fbs` | Logic16 yok | direkt diziler veya host-import kararı |
| x64 codegen | `codegen/x64/mir_x64_capability.fbs` ve emitter | `&`/`^` hatalı | `&=AND`, `^=XOR`, `**=POW` düzelt |
| Surface | `surface/uxb_surface_registry.fbs`, bridge | Logic16 görünmez | OPERATOR/EXPRESSION_OPERATOR olarak ekle |
| Tests | `tests/operator_logic16_all_layers` | test yok | truth table, equality, AST/MIR/JS/WAT/x64 gate testleri ekle |
