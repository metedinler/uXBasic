uXBasic TRUE/FALSE ve 16 Mantıksal Operatör Kesin Söz Dizimi
=================================================================

Bu belge, operatör yamasına ek kesin karardır. Önceki operatör paketinde `==`, `=`, `**`, `^`, `|>` ve işlem öncelikleri düzeltilmişti. Bu ek karar iki büyük eksikliği kapatır:

1. `TRUE` ve `FALSE` dil anahtar sözcüğü ve boolean literal olmalıdır.
2. AND, OR, NOT, XOR ailesinden üretilebilen 16 iki girdili doğruluk fonksiyonu dil yüzeyi, kitap, test verisi ve LLM eğitim verisinde açıkça yer almalıdır.

Bu karar uXBasic'in BASIC kökenini korur. Eski BASIC belgelerinde `TRUE`, `FALSE`, `AND`, `OR`, `NOT`, `XOR`, `EQV`, `IMP` gibi mantık işleçleri görülebilir. Yapay zeka eğitiminde bu belgelerden veri alınacağı için bu terimler belirsiz bırakılmamalıdır.

1. TRUE ve FALSE
-----------------

`TRUE` doğru değerdir. Sayısal karşılığı `1` kabul edilir.
`FALSE` yanlış değerdir. Sayısal karşılığı `0` kabul edilir.

Sözdizimi:

    DIM aktif AS BOOLEAN
    aktif = TRUE
    IF aktif = TRUE THEN PRINT "aktif"
    IF aktif THEN PRINT "aktif"
    IF NOT aktif THEN PRINT "kapali"

Lexer kararı:

    TRUE  -> KEYWORD TRUE
    FALSE -> KEYWORD FALSE

Parser kararı:

    TRUE  -> AST BOOLEAN value="TRUE"  op="1"
    FALSE -> AST BOOLEAN value="FALSE" op="0"

MIR kararı:

    TRUE  -> MIR_CONST_BOOL 1 veya MIR_CONST_I32 1
    FALSE -> MIR_CONST_BOOL 0 veya MIR_CONST_I32 0

2. Eşitlik kararı
-----------------

BASIC uyumu için:

    a = b          statement başında atama
    IF a = b THEN  koşul/ifade içinde eşitlik karşılaştırması
    IF a == b THEN açık eşitlik karşılaştırması

Bu karar değişmez. `=` hem atama hem karşılaştırma olabilir; ayrım bağlamdan yapılır.

3. 16 iki girdili doğruluk fonksiyonu
-------------------------------------

A ve B iki boolean girdi olsun. Girdi sırası tabloda şu şekildedir:

    00, 01, 10, 11

| No | Ad | Diğer adlar | Sonuç dizisi | Formül | Görev |
|---:|---|---|---|---|---|
| 0 | FALSE | ZERO | 0000 | A AND NOT A | Her zaman yanlış döndürür. |
| 1 | AND |  | 0001 | A AND B | İkisi de doğruysa doğru. |
| 2 | NIMP | A_ONLY, A_AND_NOT_B | 0010 | A AND NOT B | A doğru, B yanlışsa doğru. |
| 3 | ID_A | A | 0011 | A | Sadece A'nın değerini döndürür. |
| 4 | NCIMP | B_ONLY, NOT_A_AND_B | 0100 | NOT A AND B | B doğru, A yanlışsa doğru. |
| 5 | ID_B | B | 0101 | B | Sadece B'nin değerini döndürür. |
| 6 | XOR | NEQ | 0110 | A XOR B | Farklıysa doğru. |
| 7 | OR |  | 0111 | A OR B | En az biri doğruysa doğru. |
| 8 | NOR |  | 1000 | NOT (A OR B) | İkisi de yanlışsa doğru. |
| 9 | XNOR | NXOR, EQV, EQA, IFF | 1001 | NOT (A XOR B) | Aynıysa doğru. |
| 10 | NOT_B |  | 1010 | NOT B | B'nin tersini döndürür. |
| 11 | CIMP | B_IMP_A | 1011 | A OR NOT B | B ise A. |
| 12 | NOT_A |  | 1100 | NOT A | A'nın tersini döndürür. |
| 13 | IMP | A_IMP_B | 1101 | NOT A OR B | A ise B. |
| 14 | NAND |  | 1110 | NOT (A AND B) | İkisi de doğruysa yanlış. |
| 15 | TRUE | ONE | 1111 | A OR NOT A | Her zaman doğru döndürür. |

4. Kullanım biçimi
------------------

Temel kullanımlar:

    IF A AND B THEN PRINT "ikisi de dogru"
    IF A OR B THEN PRINT "en az biri dogru"
    IF A XOR B THEN PRINT "farkli"
    IF A NAND B THEN PRINT "ikisi birden dogru degil"
    IF A NOR B THEN PRINT "ikisi de yanlis"
    IF A XNOR B THEN PRINT "ayni"
    IF A IMP B THEN PRINT "A ise B"
    IF A EQV B THEN PRINT "denk"

Kimlik ve sınır operatörleri eğitim, mantık tablosu ve dijital devre anlatımı için korunur:

    sonuc = A ID_A B     ' sonuc A olur
    sonuc = A ID_B B     ' sonuc B olur
    sonuc = A NOT_A B    ' sonuc NOT A olur
    sonuc = A NOT_B B    ' sonuc NOT B olur
    sonuc = A TRUE B     ' sonuc TRUE olur
    sonuc = A FALSE B    ' sonuc FALSE olur

Not: `TRUE` ve `FALSE` tek başına boolean literal olarak da kullanılır. Parser bağlamı şudur:

    TRUE          -> literal
    A TRUE B      -> iki girdili her zaman doğru operatörü
    FALSE         -> literal
    A FALSE B     -> iki girdili her zaman yanlış operatörü

6. Boolean ve bitwise ayrımı
----------------------------

uXBasic'te iki ayrı düşünce vardır:

- Boolean mantık: `TRUE`, `FALSE`, `AND`, `OR`, `NOT`, `XOR`, `NAND`, `IMP`, `EQV`.
- Bit işlemleri: `&`, `|`, `^`, `~`, `<<`, `>>`, `SHL`, `SHR`, `ROL`, `ROR`.

`AND`, `OR`, `XOR` BASIC kökeni nedeniyle integer üzerinde bit düzeyi davranabilir; fakat `BOOLEAN` tipli ifadede mantıksal davranış beklenir. Kitapta ve LLM eğitim verisinde şu kural yazılmalıdır:

    BOOLEAN ile kullanılırsa mantık işlemi.
    Tam sayı ile kullanılırsa bit işlemi.
    Belirsizlik varsa bit işlemi için sembollü &, |, ^ kullan.
    Mantık işlemi için TRUE/FALSE ve açık karşılaştırma kullan.

7. Katmanlarda yapılacak zorunlu değişiklikler
----------------------------------------------

A. lexer_keyword_table.fbs

- TRUE ve FALSE keyword olmalı.
- 16 doğruluk fonksiyonu keyword olmalı.
- Alias adları da keyword olmalı: ZERO, ONE, NXOR, EQV, EQA, IFF.

B. parser_expr.fbs

- TRUE/FALSE literal olarak AST BOOLEAN üretmeli.
- Expression parser 16 mantık operatörünü tanımalı.
- `=` expression içinde karşılaştırma olarak çalışmalı.
- `a = b` statement bağlamında atama kalmalı.

C. MIR

- TRUE/FALSE sabitleri MIR sabitine inmeli.
- 16 mantık işleci MIR opcode ya da canonical runtime op olarak haritalanmalı.
- En azından şu canonical op adları olmalı:

    MIR_BOOL_FALSE
    MIR_BOOL_TRUE
    MIR_AND
    MIR_OR
    MIR_XOR
    MIR_NOT
    MIR_NAND
    MIR_NOR
    MIR_XNOR
    MIR_IMP
    MIR_CIMP
    MIR_NIMP
    MIR_NCIMP
    MIR_ID_A
    MIR_ID_B
    MIR_NOT_A
    MIR_NOT_B

D. Backend ve JS/WASM

İlk sağlam çözüm: yeni mantık op'larını runtime/helper çağrısına indir.
İkinci aşama: JS/WAT doğrudan ifade üreticisi ekle.

8. Test zorunluluğu
-------------------

Aşağıdaki testler PASS olmadan yama tamam sayılmaz:

    TRUE literal parse edilir.
    FALSE literal parse edilir.
    IF TRUE THEN çalışır.
    IF FALSE THEN ELSE dalı çalışır.
    IF A = B THEN eşitlik karşılaştırmasıdır.
    IF A == B THEN eşitlik karşılaştırmasıdır.
    16 doğruluk fonksiyonu 00,01,10,11 kombinasyonunda beklenen tabloyu üretir.
    tokens.json içinde TRUE/FALSE KEYWORD olarak görünür.
    AST içinde BOOLEAN node oluşur.
    MIR içinde boolean sabit ve boolean op görünür.

9. Kitap ve LLM eğitim notu
---------------------------

Kitaplara şu bölüm eklenmelidir:

    TRUE/FALSE sabitleri
    16 doğruluk fonksiyonu
    doğruluk tablosu
    işlem önceliği
    boolean/bitwise ayrımı
    BASIC uyumu: IF a = b THEN
    modern açık eşitlik: IF a == b THEN

LLM eğitim verisinde her mantık operatörü için şu örnek aileleri üretilmelidir:

    operator_logic16_001_truth_table.uxb
    operator_logic16_002_if_equal_basic.uxb
    operator_logic16_003_digital_gate.uxb
    operator_logic16_004_sensor_decision.uxb
    operator_logic16_005_qbasic_translation.uxb
