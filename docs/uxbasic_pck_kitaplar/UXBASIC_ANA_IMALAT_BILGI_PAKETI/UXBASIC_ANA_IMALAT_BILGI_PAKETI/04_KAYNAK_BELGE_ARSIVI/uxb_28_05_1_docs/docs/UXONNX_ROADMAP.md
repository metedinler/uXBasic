# UXONNX roadmap

1. CPU F32 single-input/single-output inference. Done in this package.
2. Multi-input/multi-output inference.
3. I64 / F64 / string tensor support.
4. Dynamic shape helper functions.
5. DirectML execution provider package for Windows.
6. CUDA execution provider package for NVIDIA systems.
7. Model metadata, operator list and IO schema export.
8. Integration with uxdataset/uxtensor/uxnn3.
