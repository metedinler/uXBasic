JSON / BUILD ROOT POLICY - 2026-06-05

Kullanici karari:
- Varsayilan genel build koku: build/
- Butun JSON/CSV rapor ciktilari genel build kokunun altindaki json/<run_id>/ klasorune gider.
- Kullanici --artifact-root <kok> verirse bu deger genel build koku sayilir.
- Bu durumda JSON/CSV rapor ciktilari <kok>/json/<run_id>/ altina gider.
- ASM/OBJ/EXE/DLL/WEB gibi diger uretilen dosyalar ayni genel build kokunun ayri alt klasorlerinde tutulur.

Yeni kokler:
- buildRoot: build veya --artifact-root ile verilen kok
- jsonRoot/artifactRoot: <buildRoot>/json/<run_id>
- asmRoot: <buildRoot>/asm/<run_id>
- objRoot: <buildRoot>/obj/<run_id>
- exeRoot: <buildRoot>/exe/<run_id>
- dllRoot: <buildRoot>/dll/<run_id>
- webRoot: <buildRoot>/web/<run_id>

Uyumluluk notu:
- Kodun bircok yerinde artifactRoot JSON kok gibi kullanildigi icin artifactRoot = jsonRoot olarak korundu.
- ASM/EXE gibi dosyalar icin yeni asmRoot/exeRoot alanlari kullanildi.
- Dosya silinmedi.

Duzeltilen yanlis beyan:
- Onceki kaynakta aktif kok dist/artifacts veya json/<run_id> karisik durumdaydi.
- Bu paket, aktif politikayi build/json/<run_id> ve build/{asm,obj,exe,dll,web}/<run_id> seklinde netlestirir.
