# UXONNX2 Roadmap

1. Sequence/map output desteği.
2. Dynamic shape helper: -1 dim için runtime reshape.
3. Tokenizer wrapper: HuggingFace tokenizer JSON / sentencepiece.
4. Image preprocessing: resize, normalize, CHW/NHWC dönüştürme.
5. DirectML/CUDA paket ayrımı ve otomatik provider registry.
6. I/O binding ve pinned memory.
