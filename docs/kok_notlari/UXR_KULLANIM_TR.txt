UXR.PY KULLANIM NOTU
====================

Program adı değiştirilmedi: uxr.py

Bu program nedir?
-----------------
uxr.py ana uXBasic derleyicisi değildir. uXBasic testlerini bulan, seçen,
mevcut uxb_differential_project_runner.py aracını çağıran ve çıkan sonuçları
raporlayan test koşucusu / ters analiz aracıdır.

Neyi çalıştırır?
----------------
Varsa uxb_differential_project_runner.py dosyasını bulup test kaynaklarını onunla
çalıştırır. Şu katmanların durumunu raporlar:

- AST yorumlayıcı
- MIR yorumlayıcı
- x64 AST kod üretimi
- MIR x64 kod üretimi

Raporları nereye yazar?
-----------------------
Varsayılan rapor klasörü:

  report\uxr

reverse komutunun varsayılan rapor klasörü:

  report\uxr_reverse

Nasıl çalıştırılır?
-------------------
Yardım:

  python uxr.py --help
  python uxr.py run --help
  python uxr.py reverse --help

Testleri listeleme:

  python uxr.py list

Hızlı smoke test:

  python uxr.py run --quick

Belirli testler:

  python uxr.py run --ids 1,2,3

Belirli grup:

  python uxr.py run --groups lexer,operator --max-tests 20

Var olan run klasörünü raporlama:

  python uxr.py reverse

Proje kökü otomatik bulunamazsa:

  python uxr.py run --root C:\UXBc\uxb --quick

Rapor klasörü değiştirme:

  python uxr.py run --out report\benim_raporum --quick

Notlar
------
- Program proje kökünden de çalışabilir.
- Program bulunduğu klasörden de çalışabilir.
- --root verilmezse proje kökünü otomatik arar.
- report\ klasörü otomatik oluşturulur.
- İngilizce dosya adları eski otomasyonlar bozulmasın diye korunur.
- Türkçe adlarla ek rapor kopyaları da yazılır:
  uxr_rapor.md
  uxr_ozet.json
  uxr_sonuclar.csv
  uxr_sonuclar.json
  uxr_katman_detaylari.csv
