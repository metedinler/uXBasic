uXBasic Derin Analiz Aracı - Türkçe Kullanım
============================================

Dosyalar:
  uxb_derin_analiz.py = uxbrarp.py
  run_uxb_derin_analiz.bat

En kolay kullanım:
  1) uxb_derin_analiz.py dosyasını uXBasic proje köküne koy.
  2) PowerShell veya CMD içinde proje köküne gel.
  3) Çalıştır:
       python uxb_derin_analiz.py -r runs

Uzun yol vermek gerekirse:
  python uxb_derin_analiz.py -r "C:\UXBc\uxb\_work\projects\default\runs"

Varsayılan çıktı klasörü:
  reports\uxbrarp

Üretilen dosyalar:
  reports\uxbrarp\calisma_duzeyi_analizi.csv
  reports\uxbrarp\test_ozeti.csv
  reports\uxbrarp\ozellik_ozeti.csv
  reports\uxbrarp\katman_hata_ozeti.csv
  reports\uxbrarp\durum_pivot.csv
  reports\uxbrarp\cikti_uyusmazlik_detaylari.csv
  reports\uxbrarp\UXBc_calismalari_derin_analiz_raporu.md

Yardım:
  python uxb_derin_analiz.py --help

Runs klasörü arama:
  python uxb_derin_analiz.py --runs-ara

Önemli değişiklikler:
  - Eski reports/current/uxbrarp yolu yerine reports/uxbrarp kullanılır.
  - Eski Path(__file__).resolve().parents[4] bağımlılığı kaldırıldı.
  - argparse tabanlı Türkçe --help eklendi.
  - Ekran mesajları, rapor başlıkları ve CSV alan adları Türkçeleştirildi.
  - JSON okuma hatası, boş runs klasörü ve eksik differential_report.json durumlarında program tamamen çökmez; rapora durum yazar.
